## 🛠️ How GitHub Pages Works

This repository takes advantage of GitHub's free static site hosting:

1. **Any code pushed to `main` branch** → Automatically deployed to the live URL
2. **No build step required** — GitHub Pages serves HTML, CSS, and JS directly
3. **Free custom domain support** — Can add a `CNAME` file for a custom domain
